STEELCONTROL - CORREÇÃO CODE FREEZE

1. Copie a pasta tools para a raiz do projeto.
   O arquivo ficará em:
   tools/update-code-freeze.mjs

2. Na raiz do projeto, rode:
   node tools/update-code-freeze.mjs

3. Valide:
   npm run check:freeze

4. Se aparecer [FREEZE] OK, rode:
   npm run quality

5. Depois:
   git add CODE_FREEZE.sha256 tools/update-code-freeze.mjs
   git commit -m "Atualiza code freeze da versão final"
   git push

IMPORTANTE:
Só faça isso depois de confirmar que as alterações atuais são as que você quer
congelar como versão final do TCC.
