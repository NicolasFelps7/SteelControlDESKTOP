STEELCONTROL V7 — FACIAL OBRIGATÓRIA + UI INSTANTÂNEA

1. Extraia este ZIP sobre o projeto DESKTOP/BACKEND atual e substitua os arquivos.
2. Reinicie o backend.
3. O fluxo de novo cadastro agora é:
   dados -> código de e-mail -> prova de vida/facial -> transação cria empresa + administrador + face.
4. Se a facial falhar, a conta NÃO é criada. O usuário deve tentar a facial novamente.
5. A etapa facial expira após 15 minutos; se expirar, o cadastro precisa ser iniciado novamente.
6. Ações de máquinas e funcionários atualizadas neste patch não usam reload da página nem atraso artificial.
